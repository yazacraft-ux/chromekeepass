ChromeKeePass is an independent Chrome browser extension and website that provides KeePass integration, local password generation, and password suggestions on account-creation forms. Version 0.3.0 is publicly available on the Chrome Web Store.

Password-management and browser-extension software can be security-sensitive, and users remain responsible for protecting their devices, KeePass databases, master passwords, recovery material, and accounts.

KeePass integration

KeePass integration requires a compatible local KeePassHttp setup. ChromeKeePass does not guarantee compatibility with every KeePass configuration, website, login form, or third-party plugin.

Generated passwords

ChromeKeePass can generate random passwords locally. Users are responsible for safely storing generated passwords before relying on them for an account.
